# BEATPAD

**A four-key rhythm game controller powered by Arduino.**

BEATPAD is an interactive rhythm game inspired by **Magical Tiles**, featuring four colour-coded keys that challenge players to follow sequences and match the rhythm.

## Features

- Four LED-lit playing keys: Red, Blue, Green and Yellow.
- Song selection and gameplay controls.
- Three difficulty modes.
- I2C LCD for displaying scores and game information.
- Buzzer for audio feedback.
- Custom-designed 3D enclosure.

## Hardware

- Arduino Uno R3
- 16×2 I2C LCD
- 4 LEDs
- 7 Pushbuttons
- Buzzer
- Resistors
- Power supply

## Software

- Arduino C/C++
- Tinkercad Circuits
- 3D CAD modelling
